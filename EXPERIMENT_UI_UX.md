# Experiment CA — UI reimagination

Parent branch: `experiment/CA_expansion`. This branch: `experiment/CA_ui_reimagination`.

The decision log is [`../crm_backend/docs/EXPERIMENT_UI_UX.md`](../crm_backend/docs/EXPERIMENT_UI_UX.md).

Navigation is a desk: Today, Leads, Jobs, Schedule, and Money, with office tools grouped underneath. A job is a workspace with Work, Money, Site, and Record. Settings saves density and whether Today opens on the queue or on money. Those preferences come from `users.ui_preferences`.
